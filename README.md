# ジョーの大冒険（ジョーダンジョン）

スマートフォン・タブレット向けの、オリジナル恐竜と冒険する見下ろし型ターン制ローグライク試作版です。画像・音声・ゲームライブラリのダウンロードは不要です。

## 遊ぶ / 起動

このリポジトリはそのまま静的Webサーバーで配信できます。ビルドや npm install は不要です。

```sh
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開きます。ES Modulesを使うため、`index.html` をファイルとして直接開くのではなくHTTP経由で起動してください。GitHub Pagesで配信する場合は、マージ後にリポジトリの Pages 設定で `main` の `/ (root)` を選択できます。このPR自体はPagesの設定・公開を変更しません。

## 遊び方

- 「ダンジョンへ！」で出発。矢印1回につき1歩。押しっぱなしでは移動しません。
- 敵の方向へ移動すると攻撃。攻撃ボタンは黄色い矢印の方向を攻撃します。
- 階段と宝箱の上で「足元」。地下10階のおたからに到達するとクリアです。
- どうぐを使う・投げる・置くと1ターン。メニューを開閉するだけでは進みません。
- 恐竜に向き、隣で恐竜の肉を使うか、肉を投げると75%で仲間になります。
- 音は最初OFF。右上のボタンでONにできます。効果音はWeb Audioで合成します。
- 矢印 / WASD：移動、Q/E/Z/C：斜め、Space：攻撃、I：道具、F：足元、`.`：待つ。テンキーも対応。

## 実装済み

- 到達可能性を保証した9部屋と通路のランダム生成、地下1〜10階、ミニマップ、部屋・通路の視界。
- 4種類の敵：ぷるりん、ピコラプトル、まるよろい、そらひらり。階層に応じて種類と強さが変わります。
- 7種類の道具：回復、剣、盾、パン、石、巻物、恐竜の肉。かばん16枠、装備、投擲、床置き。
- HP・攻撃・防御・経験値・レベル。5歩で満腹度が1減り、空腹時は3ターンごとに1ダメージ。
- 恐竜1体が同行。ラプトルは高攻撃、アンキロは高防御・移動が隔ターン、プテラは斜めの角を飛び越せます。壁マス自体には入りません。
- 地下3階以降、30%でモンスターハウス。初回入室時に敵が出現。宝箱・道具が多く、敵は最初少し休んでいます。
- 失敗時もコイン60%、道具3個、装備、タマゴ、新しく仲良くなった恐竜を持ち帰り。クリア時はコイン・かばん全てを持ち帰ります。
- ジョータウン：倉庫、装備変更、出発時の道具持ち込み、道具購入、仲間選択、タマゴ孵化、恐竜育成、JPによる初期HP強化。
- 自動セーブ：町・装備・仲間・進行中のダンジョンを、各行動後とページ離脱時にlocalStorageへ保存。同じブラウザ・同じ配信元で復帰します。
- オリジナルCanvasキャラクター、ダメージ数字、揺れ、取得・階段・レベルアップ・警告、6種類の効果音。

## 構造

| ファイル | 責務 |
| --- | --- |
| `src/core/DungeonGenerator.js` | 部屋・通路・配置・視界・移動可能性 |
| `src/core/Player.js` | プレイヤー初期値と能力計算 |
| `src/core/Enemy.js` | 敵データと個体生成 |
| `src/core/Item.js` | アイテム定義 |
| `src/core/TurnManager.js` | 1行動の処理順、再入防止、空腹 |
| `src/core/GameState.js` | 戦闘・仲間・探索・町の状態遷移 |
| `src/core/SaveManager.js` | バージョン付き保存と読み込みエラー処理 |
| `src/ui/Renderer.js` | マップとキャラクターの描画 |
| `src/ui/Sound.js` | 効果音 |
| `src/main.js` | UI、入力、メニューの接続 |

ゲームロジックはDOM・Canvasに依存せず、Node.jsで検証できます。鍛冶屋や施設を増やす場合は町のアクションを追加し、将来保存形式を変更するときはSaveManagerのバージョン移行を実装してください。

## 確認

```sh
node --test tests/*.test.js
```

確認内容：1,000フロアの全床・階段到達、初期配置重複、角抜け制約、ターン再入防止、戦闘・レベル・道具・仲間、保存復帰・失敗・再挑戦、10階までの階段移動、5,000回分のランダム操作、モンスターハウス・空腹死・保存失敗。さらに敵を残した20シードの自動プレイで、回復・装備変更・戦闘をしながら10階クリアを確認します。自動プレイヤーは全地形を参照するため、子供の探索や実際の難易度を再現するものではありません。

### 未確認の範囲

今回の実行環境ではローカルHTMLをブラウザプレビューで開けず、実画面の視覚確認と実機Safariでのタッチ・効果音確認は未実施です。CSSは縦画面・横画面・セーフエリアに対応させていますが、実機での確認が必要です。

実機での最小確認：

1. iPhone縦画面とiPadでHP・マップ・8方向キーが重ならないか。
2. 1タップで1行動になり、長押し・二本指操作で拡大やテキスト選択が起きないか。
3. 道具を使う→閉じる→移動、ひと休み→閉じる→移動ができるか。
4. 音ONで攻撃・取得等が聞こえ、再読み込みで同じ階・HP・道具に戻るか。
5. 町への帰還→倉庫→再出発ができるか。

セーブは端末ローカルです。ブラウザのデータ削除や配信元URLの変更では引き継がれません。
